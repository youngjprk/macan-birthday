CARA MENJALANKAN
1. Buka index.html untuk mencoba website.
2. Ubah tanggal ulang tahun pada variabel birthday di bagian JavaScript.
3. Tambahkan file musik bernama music.mp3 di folder yang sama.
4. Ganti emoji pada bagian galeri dengan foto menggunakan tag <img>.
5. Upload folder ini ke Vercel atau Netlify agar mendapatkan link publik.

CATATAN
Template ini dibuat sebagai konsep mandiri berdasarkan fitur yang diminta. Video TikTok tidak dapat saya lihat secara langsung, sehingga tampilan belum bisa dijamin identik dengan video referensi.
